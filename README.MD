# РГЗ по HTML, CSS и JavaScript

## Тема проекта
Корпоративный сайт компании «Лента».

## Описание
В рамках расчётно-графического задания был разработан
многостраничный веб-сайт компании «Лента».

Сайт содержит:
- главную страницу;
- страницу новостей;
- страницу курса валют;
- страницу контактов;
- страницу видео.

## Используемые технологии
- HTML5
- CSS3
- JavaScript
- Chart.js
- GitHub Pages

## Реализованные возможности
- адаптивный дизайн;
- боковое меню;
- кнопка «Наверх»;
- интерактивные новости;
- калькулятор валют;
- график курса валют;
- встроенное видео;
- карта контактов.

Сайт опубликован через GitHub Pages.
